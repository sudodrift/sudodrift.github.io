Tools

Free, open source tools I maintain. None of them change the systems they check or send your data anywhere.

  • sudodrift

    A small Go tool that takes a snapshot of who can log in to a Linux server and who can become root, then tells you in plain English what changed. One static binary, no network access.

  • breach-checks

    Short shell scripts that check your own machines for one real incident each, like the LiteLLM 1.107.0 release or the swapped OVHcloud CLI. Each one goes with an article here.

  • agent-preflight

    Run it before you start a coding agent in a folder. It lists the instruction files, MCP servers and hooks the agent would load, and flags the ones worth a look.
